# Direct Downloads

## Overview

Data sets can be downloaded from the web directly to a tenant’s xfer server. This functionality is not enabled by default and has some caveats. Download functionality will need to be explicitly requested by the PI for CIS to enable it. CIS will also need to know where the data will be downloaded from so the IP addresses can be whitelisted on the campus firewall and on the xfer server. These direct download sessions are not as restricted as SFTP logins, so we limit access only to members of a special download group `sh_<tenant>_dwnld`.
