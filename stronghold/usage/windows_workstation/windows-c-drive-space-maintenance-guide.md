# Windows C: Drive Space Maintenance Guide

Windows workstations have a 2 GB per-user quota on the C: drive. If your folder exceeds this limit, Windows and installed applications may not work correctly.

Use TreeSize to find large files in your user folder and free up space.

## 1. Open TreeSize

Open the Windows search menu, type `TreeSize`, and select the app.

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-08 at 12.54.11 PM.png" alt="" width="563"><figcaption></figcaption></figure>

## 2. Scan the C: drive

In TreeSize, click **Select Directory**. Then select **Local Disk (C:)**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-07-08 at 12.40.40 PM.png" alt=""><figcaption></figcaption></figure>

## 3. Review Your User Folder

After the scan finishes, expand `C:\Users` and open your user folder.

Review the largest folders first. Delete files you no longer need, or move them to another location such as the `F:` drive.
