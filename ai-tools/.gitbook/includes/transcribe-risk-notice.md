**Data Privacy Notice:**\
The Transcribe Service is approved to handle sensitive data up to **Risk Level 3**. Before using Transcribe, please check [OIT's Data Risk Classifications](https://it.brown.edu/policies/data-risk-classifications) to understand what data can be used with Transcribe. Follow [data security best practices](../../data-privacy/transcribe-data-handling-level-3/data-security-best-practices.md) when handling sensitive data.
{% endhint %}
