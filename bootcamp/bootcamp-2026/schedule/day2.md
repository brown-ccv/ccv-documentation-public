# Day 2: Tuesday, 2 June

Hybrid sessions with a remote instructors will have CCV staff in-person to support with any questions.

## Version Control with Git | 9:30 - 10:30 EDT

_<mark style="color:$info;">**Hybrid with in-person instructor: CIT219**</mark>_

An introduction of how to get started with version control with git and GitHub. We will cover basic git controls for updating repositories, interacting with remote repositories, and branching.

[slides](https://docs.google.com/presentation/d/1-X1cQ2ilRy4aIrv7wcFkOUqYI-nwct_gRtKzJ1FIEtQ/edit?usp=sharing) | [video](https://brown.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=a127ce9d-10f3-46f7-ac47-b48201406f95)

## Intro to Containers on Oscar | 10:40 - 11:40 EDT

_<mark style="color:$info;">**Hybrid with remote instructor: CIT219**</mark>_

Discover how to make your research portable and reproducible using containers on OSCAR. This short workshop covers: container basics with Docker, HPC & Apptainer, deployment on OSCAR.

[repo](https://github.com/brown-ccv/ccv-bootcamp-intro-to-containers-oscar-2026.git) | [video](https://brown.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=7b5dccf0-5411-4dd1-a42c-b48201406f94)

## Using Python on Oscar | 1:00 - 1:30 EDT

_<mark style="color:$info;">**Hybrid with remote instructor: CIT219**</mark>_

Streamline your Python workflows on OSCAR by learning how to efficiently manage packages, dependencies, and GPU acceleration. This short, practical session covers the pros, cons, and best practices for the major environment managers available on the cluster such as venv, uv, conda, and containers.

_Prerequisites:_ Basic familiarity with Python and the command line.

_Pre-workshop Resource:_ Review the [OSCAR Python Installation Guide](https://docs.ccv.brown.edu/oscar/software/python-installs) before attending. _Bring a laptop and your CCV credentials!_

[repo](https://github.com/brown-ccv/ccv-bootcamp-using-python-on-oscar-2026) | [video](https://brown.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=173d9a90-97f0-41d3-9d76-b48201406f90)

## GPU Computing on Oscar | 1:40 - 2:30 EDT

_<mark style="color:$info;">**Hybrid with in-person instructor: CIT219**</mark>_

An introduction to GPUs, the architectures available on Oscar, submitting, running, and evaluating jobs. Using nvidia ngc containers on Oscar for deep learning, installing or building python packages, and using docker to make changes.

[slides](https://docs.google.com/presentation/d/1H29dVZb1IpiW6-WmOoAVDYc8FP0_uItfGV6hljJvPls/edit?usp=sharing) | [video](https://brown.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=9210629b-d016-4ffd-b32a-b48201406f90)

## Using LLMs and Deeplearning Models on Oscar | 2:40 - 3:30 EDT

_<mark style="color:$info;">**Hybrid with in-person instructor: CIT219**</mark>_

An introduction on using locally available and cloud LLMs on Oscar. This workshop will go through setting up [Opencode](https://opencode.ai/), Ollama server, and adding MCPs to the models. We will also look at how to run huggingface models and wandb visualizations. &#x20;

_Prerequisites:_ Familiarity with [Python](day2.md#using-python-on-oscar-or-1-00-1-30-edt) and [Oscar](day1.md#getting-started-on-oscar-or-9-30-10-50-edt). Have a [wandb](https://wandb.ai/site/) account.

[slides](https://docs.google.com/presentation/d/1u9LF8rUkjvTspljyE_zcDh782btJ0x1Lrdx4Ok157ts/edit?usp=sharing) | [video](https://brown.hosted.panopto.com/Panopto/Pages/Viewer.aspx?id=2792124a-65ae-4af2-8c78-b48201412986)
