# Day 3: Wednesday, 3 June

Today's tutorials will occur along three tracks running concurrenlty, each devoted to a different programming language. The tutorials associated with each track are listed on the corresponding tab below.

Hybrid sessions with a remote instructors will have CCV staff in-person to support with any questions.

### Using MATLAB on Oscar | 9:30 - 10:20 EDT

_<mark style="color:$info;">**Remote only**</mark>_

An introduction to using MATLAB on Oscar. Topics covered include: working with MATLAB interactively on Oscar, using the MATLAB Desktop, and using MATLAB in batch jobs.

_<mark style="color:$info;">**Remote only**</mark>_

{% tab title="Python" %}
### Intro to Python Programming I: Data types & structures, Control Flow, Functions | 1:00 - 2:50 EDT

_<mark style="color:$info;">**Hybrid with in-person instructor: CIT219**</mark>_

This short introduction to Python will teach fundamentals by way of practical applications for researchers. The goal of this session will be to write a custom function to process raw data files. Along the way we’ll learn about Python’s core concepts like data types & structure and using control flow.

[Github Repo](https://github.com/brown-ccv/ccv-bootcamp-python-2026)

### Intro to Python Programming II: Packages, Environments, Tabular Data | 3:00 - 4:30 EDT

_<mark style="color:$info;">**Hybrid with in-person instructor: CIT219**</mark>_

This session will focus on the management of research workflows and analyzing tabular data using the pandas library. This session introduces the essentials of 3rd-party packages and virtual environments, ensuring your analysis remains stable and reproducible across different machines. Through hands-on exercises, you will learn the basics of the DataFrame object to perform exploratory data analysis, data cleaning, and plotting.

[Github Repo](https://github.com/brown-ccv/ccv-bootcamp-python-2026)
{% endtab %}

[Github repo link](https://github.com/compbiocore/ccv_bootcamp_R)
