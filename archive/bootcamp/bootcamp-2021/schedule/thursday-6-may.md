# Thursday, 6 May

## Foundations for Bioinformatics Data Analyses | 9:30 - 11:00 EDT

This session we will discuss the most common file formats used in bioinformatics, some resources for accessing public datasets (like the SRA), and a few other helpful bioinformatics QC tools

## Basic Bioinformatics Workflows on Oscar: BioFlows | 11:00 - 12:00 EDT

This session will address how you can use Bioflows to manage your analysis pipelines. Bioflows will automate job scheduling, impose a standardized organization to your files and folders, and write useful log files for debugging.

## Annotation Resources for Downstream Analyses Using Bioconductor | 1:30 - 3:00 EDT

The last formal session of the day is devoted to annotation resources and downstream analyses of NGS data using R and Bioconductor. We will cover different annotation file formats, public resources for annotation data, and leveraging those resources for downstream analyses in R.

## Bioinformatics Q\&A Session | 3:00 - 4:00 EDT

We will devote the last hour of the day for your bioinformatics on Oscar questions.
