# APMA Research Systems

The Research Systems Linux team (Nathan Wood, Paulo Baptista, Mike Antonelli) provides specialized tech support for the Division of Applied Math.

We deploy physical Linux computers and GPU workstations, manage virtual machines and containers, help with research software, and act as a bridge to the resources offered by the Office of Information and Technology (OIT).

Documentation for some of the services we provide:

* [Linux Workstations](services/linux.md)
* [Wuzhui GPU Server](services/wuzhui.md)
* [Apache Web Hosting](services/apache.md)
