# Commercial Software

The division manages licenses for commercial research software. The software may not be installed by default on workstations, but can be made available upon request.

Be sure to close out of these applications when you are not actively using them to free up the licenses for other users.

*   **Dassault Systems Abaqus:** Two simultaneous licenses are available. It can be launched from a terminal window with the following command:

    `/var/DassaultSystemes/SIMULIA/Commands/abaqus cae`
*   **Fidelity Pointwise**: A single license is available. It can be launched from a terminal window with the following command:

    `/opt/pointwise/PointwiseV18.6R3/pointwise`
*   **Mathworks Matlab:** Unlimited campus-wide license. It be launched from the Applications graphical menu, or with the following command:

    `matlab`
