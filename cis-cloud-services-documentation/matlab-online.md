# Matlab Online

* [MATLAB Online](https://matlab.mathworks.com) provides an online platform to run MATLAB from your Browser
* [MATLAB Grader](https://grader.mathworks.com/) integrates with Canvas and can automate testing and grading. 
  * Contact [dld@brown.edu](mailto:dld@brown.edu) to add this tool to your course. Then follow the instructions provided by Mathworks for [creating MATLAB coding problems](https://www.mathworks.com/help/matlabgrader/ug/integrate-matlab-grader-with-canvas.html#mw_4424875e-26ba-41cb-bb4e-581596079014) as Canvas assignments.
