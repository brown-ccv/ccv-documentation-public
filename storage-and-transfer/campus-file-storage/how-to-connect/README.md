# How to Connect

Campus File Storage (Files22) is accessible directly from the Brown University campus network or from off-campus locations via a secure VPN. The system supports native integration with Windows, macOS, and Linux; specific configuration steps for each operating system are detailed below. Additionally, files22 can be accessed through the university’s Remote App servers.

For users operating within the OSCAR high-performance computing environment, access is restricted to research shares only. Please refer to the Center for Computation and Visualization (CCV) documentation for specific instructions on connecting to these research shares from within the OSCAR environment.
