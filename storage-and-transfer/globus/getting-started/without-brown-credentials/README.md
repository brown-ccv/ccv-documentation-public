# Without Brown Credentials

**DO NOT follow these instructions if you have a Brown account**. These instructions are intended for users who do not have a Brown Account. Instead visit [log-in-with-brown-account.md](../log-in-with-brown-account.md "mention")

To access Globus, you need a Globus ID. You can follow the instructions under [create-globus-id.md](create-globus-id.md "mention") to create such an account. To log into an already existing account, follow the instructions under [log-in-to-globus.md](log-in-to-globus.md "mention")
