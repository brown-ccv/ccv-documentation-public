# With Brown Credentials

You should log in using your **Brown University credentials.** To do so, select Brown University from the list of organizations. Please DO NOT use the `Sign In with Google` option.

<figure><img src="../../.gitbook/assets/image (8).png" alt="Screenshot of Globus Login Page using Brown Credentials."><figcaption></figcaption></figure>

{% hint style="danger" %}
_If you don’t have your ‘**uidnumber**’ and ‘**gidnumber'** set properly, you will not be able to create a collection. You might end up with an error page like '_&#x49;dentity set contains an identity from an allowed domain, but it does not map to a valid username for this connector'. _Please contact ​help@brown.edu or your local ITSC to resolve the issue._
{% endhint %}
