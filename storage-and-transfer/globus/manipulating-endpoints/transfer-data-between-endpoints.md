# Transfer Data between Collections

One can transfer data between collections if the two collections are either created using the same account or if they are created using different accounts but those accounts are [already linked](../creating-endpoints/link-accounts-for-different-endpoints.md).

1\. Log into either Globus Web App or Globus Connect Personal, click the 'File Manager' icon in the left panel and find the two collections using the search bar or your bookmarks (which appear as an option beneath the search bar once it has been clicked). The order of the two collections does not matter. Select a file or folder to transfer (Figure 1). In the example, `Initial_Results.txt` has been selected from the BrownU\_JaneSmith\_GDrive collection. The 'Start' button above this collection will change color to indicate that a transfer is now possible.

![Figure 1. File Manager Interface](<../../.gitbook/assets/Screenshot 2020-11-12 094157.png>)

{% hint style="info" %}
You can transfer multiple files/folders located in the same directory by selecting the checkboxes next to each file/folder you wish to transfer. Everything you have selected will be grouped into one transfer request.
{% endhint %}

2\. Before making the transfer, open the 'Transfer & Sync Options' menu in between the 'Start' buttons to label the transfer and verify that the settings are to your liking (Figure 2).

![Figure 2. Transfer & Sync Options Menu](<../../.gitbook/assets/Screenshot 2020-11-12 094432.png>)

{% hint style="info" %}
If one of the collections involved in the transfer requires encryption, the 'encrypt transfer' checkbox will be automatically selected and you will not be able to deselect it.
{% endhint %}

We generally recommend that you label your transfers in order to distinguish them from each other and encrypt them for additional security. For more information on a specific setting, click on the information icon at the end of the short description.

{% hint style="info" %}
The "Preserving the source file modification times" checkbox can be useful for keeping track of when files were originally created rather than when they were most recently transferred between collections.
{% endhint %}

Once you have labeled your transfer and adjusted the settings, you are ready to make the request.

3\. Click the valid 'Start' button (the darkened one on the side of the source collection). A message will be displayed when the transfer starts/ends. Click the 'View details' link in the message (Figure 3).

![Figure 3. Confirmation](<../../.gitbook/assets/Screen Shot 2020-11-01 at 10.13.32 AM.png>)

4\. Details of the transfer are displayed (Figure 4).

![Figure 4. Activity Details](<../../.gitbook/assets/Screen Shot 2020-11-01 at 10.13.45 AM.png>)

{% hint style="success" %}
When you receive an email notifying you of a successful transfer, the process is complete!
{% endhint %}
