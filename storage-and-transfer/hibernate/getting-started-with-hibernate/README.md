# Getting Started with Hibernate

The following data sources can be accessed for archiving, deleting, or recovering from Hibernate:

* Campus File Storage (files22)
* Oscar Data

Hibernate service uses a data analytics tool called [Starfish](https://docs.ccv.brown.edu/storage-and-transfer/hibernate/starfish). Starfish uses a feature called '<mark style="color:blue;">zone</mark>' to facilitate researchers with their own unique view of storage. A 'zone' combines storage owned by a researcher on different storage platforms providing a holistic view.

So, to begin using Hibernate service, a PI/researcher should request a [zone](/broken/pages/-MkIHyEy2ioVrfcSKznN) that also provides access to the Starfish tool. Please complete the [Hibernate Service Request form](https://brown.atlassian.net/servicedesk/customer/portal/16/group/55/create/468) to select the data sources that should be accessible within your zone.
