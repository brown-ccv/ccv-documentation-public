# Zones

The “zones” feature is designed to allow _**zone admins**_ like primary investigators, group leads, department heads, departmental IT staff, etc. to access some Starfish features. A zone is defined by its name, and directories added to the zone. Each zone can also have a unique set of tags, created and managed by the starfish admins, available to the zone’s admins to apply to files, directories, or directory trees.

Starfish zones interface primarily provides two views/tabs.

1. The **Browser Tab** contains a subset (or the full set) of the site’s directory trees, their sizes, last modified times, ownership, costs, etc as shown in Figure 1.
2. The **Analytics Tab** provides a summary of the storage, zone users can view summaries of total size, cost, and the number of files and directories as shown in Figure 2. Users can also find a graph showing how storage is spread across subdirectories and a history graph, showing size, file count changes over time, and directory coldness as shown in Figure 3.
