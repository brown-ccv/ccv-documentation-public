# Clean-Up

When large\* quantities of data need to be deleted, doing it from a client might be very tedious as it takes a long time and session(s) cannot be disconnected. Starfish tool can be used to tag such data and server-side backend processes can delete the data based on tags.

{% hint style="info" %}
**\*** Folders with size >1TB or >500K objects.
{% endhint %}
