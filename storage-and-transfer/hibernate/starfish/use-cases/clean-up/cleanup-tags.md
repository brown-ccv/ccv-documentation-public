# Cleanup Tags

While custom delete tags can be configured upon request, currently we are offering cleanup functionality as part of our [Hibernate](https://app.gitbook.com/o/-LLCCXzgv2-pRyGi-QB2/s/-MkHurDt6-E9sNlIWBI2/) service. `Delete` tag in Hibernate service will provide researchers a convenient way to submit a request to the storage team to delete large folders efficiently.

**Step 1:** Navigate into the directory you wish to delete

**Step 2:** Right-click on the particular directory and select <mark style="color:green;">Tags > Action Tags > A Hibernate: Delete</mark>

**Step 3:** Once you select that, the <mark style="color:green;">A Hibernate: Delete</mark> tag should appear on the directory

{% hint style="danger" %}
**Hibernate:Delete** tag will only work on <mark style="color:blue;">Folders</mark> and **NOT** on <mark style="color:blue;">individual files</mark>. We also recommend tagging a folder with >100K objects.
{% endhint %}

**Step 4:** Repeat the procedure to tag all relevant folders and files.

**Step 5:** Once tagging is complete, please complete the [Hibernate Service Request form](https://brown.atlassian.net/servicedesk/customer/portal/16/group/55/create/468) and select the appropriate action tag. This will automatically submit a ticket to the storage team to start the appropriate process.
